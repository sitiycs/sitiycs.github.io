好问题不一定宏大。一个好问题有时只是：

```text
这个 tensor 的 shape 是什么？
```

因为它会把人从迷雾里拉回现实。

我现在最需要的不是问得漂亮，而是问得能把世界照亮一点，把下一步变清楚一点。

<!--more-->

## 理解事物本身

这类问题帮我知道“它是什么”。

- 点云到底是什么？
- 一个点表示现实中的什么？
- 模型看到的是现实，还是现实的某种表示？
- Transformer 到底在变换什么？
- 线性代数里的矩阵为什么能表示空间变换？
- 一个 AI 系统从输入到输出，中间经过了哪些层？
- 我现在面对的是数学问题、工程问题，还是实验问题？

这类问题适合在学习新概念时问。

## 理解表示

很多痛苦来自“我以为我在看现实，其实我只是在看现实的一个表示”。

- 这个数据保留了现实里的什么？
- 它丢失了什么？
- 点云为什么不是物体本身？
- 这份数据有没有噪声？
- 坐标系是什么？
- 单位是什么？
- 这个模型输入的 shape 是什么？
- 这个图、这个 loss、这个 success rate 真的代表我以为的东西吗？

做 AI、点云、机器学习时，这类问题尤其重要。

## 理解因果和机制

这类问题帮我知道“为什么会这样”。

- 为什么加噪声以后效果变差？
- 为什么 randomize block initial position 能测试泛化？
- 为什么 global point cloud 可能更好，也可能更差？
- 为什么模型在训练集表现好，测试时会崩？
- 为什么一个系统看起来聪明，但一换场景就失败？
- 为什么一个社会规则会让人这样行动？
- 为什么一个人嘴上说 A，实际在乎 B？

这类问题会把我从现象带到结构。

## 行动问题

这类问题最能救人，因为它让下一步变清楚。

- 我现在最小可以验证什么？
- 如果只有两小时，我应该先做哪一步？
- 什么结果算跑通？
- 什么结果算失败？
- 我能不能先做一个 toy example？
- 有没有一个最小实验能说明问题？
- 我今天能留下什么产物？
- 我明天第一步打开哪个文件、看哪个变量、跑哪个命令？

当我焦虑时，优先问行动问题。

## 关于自己的问题

这类问题不是为了审判自己，而是为了看清自己。

- 我现在是真的不懂，还是被问题吓到了？
- 我是在逃避，还是需要休息？
- 我想证明自己，还是想真的学会？
- 我羡慕别人什么？
- 我害怕的具体是什么？
- 我做什么事情时会感觉自己是活的？
- 我希望自己成为一个怎样的人？
- 我今天做的事情，会不会让明天的我更有力量？

这些问题要慢慢问，不要一次问到崩溃。

## 把大问题改写成小问题

有些问题太大，会把我压住。它们需要被改写。

```text
我行不行？
```

改成：

```text
明天我能做出什么小证据，证明我在变强？
```

```text
我有没有天赋？
```

改成：

```text
我在哪个环节卡住了？概念、代码、实验，还是表达？
```

```text
我能不能改变世界？
```

改成：

```text
我能不能让这个系统比昨天更可靠一点？
```

```text
我到底是谁？
```

改成：

```text
我反复在意什么？我愿意为什么付出时间？
```

```text
人生有什么意义？
```

改成：

```text
即使我现在还不知道终极意义，今天有什么事仍然值得我认真做？
```

大问题不是不能问。只是它们需要小问题来支撑。

## 明天可以问的点云问题

如果明天做 diffusion3D 相关任务，可以先问这些：

- 当前点云来自哪里？相机、仿真环境，还是预处理后的数据？
- 点云 shape 是什么？`N x 3` 还是 `N x 6`？
- 每个点的坐标系是什么？camera frame、world frame，还是 robot frame？
- global point cloud 和 local point cloud 的区别在哪里？
- 点云有没有经过 crop、sample、normalize？
- block 的位置变化以后，点云坐标有没有同步变化？
- 加噪声是加在原始点云，还是模型输入前的点云？
- 噪声大小的单位是什么？米，还是归一化后的数值？
- randomize block initial position 的范围多大才合理？
- 如果效果变差，我如何判断是坐标错了、噪声太大，还是模型不鲁棒？

这些问题比“我会不会做”更有用。

## 每天固定问 7 个问题

这 7 个问题可以放进学习日志：

```text
1. 我今天面对的对象是什么？
2. 它是如何被表示的？
3. 这个表示保留了什么，丢失了什么？
4. 我现在最不懂的地方是什么？
5. 我能做的最小实验是什么？
6. 什么结果会改变我的判断？
7. 明天第一步是什么？
```

它们可以用在点云、机器学习、软件开发、算法竞赛、人情世故、社会观察和哲学思考上。

## 长期值得问的问题

- 我是在接近现实，还是在逃进概念？
- 我是在积累能力，还是在积累焦虑？
- 我有没有把问题拆到可以行动的程度？
- 我有没有留下作品、记录或证据？
- 我有没有诚实面对自己看不懂的地方？
- 我有没有对别人和自己都保留一点善意？

今天最值得保留的问题是：

```text
明天，我能不能让一个抽象的东西变具体一点？
```

比如点云。

比如坐标。

比如噪声。

比如模型失败的原因。

比如我自己心里的不确定。

只要我能把一个模糊的东西变具体，我就在前进。
